# Kitchen Dashboard

A clock, weather, kitchen timers and a large-print recipe stand, made for an old iPad.

Open https://williampage1971-cmd.github.io/kitchen/ in Safari, then Share → Add to Home Screen.

## Adding recipes
- **From a recipe book:** send photos of the pages to Claude and ask it to add them. They go into
  `recipes.json` here, show up on the iPad automatically, and are backed up.
- **On the iPad:** tap "+ Add recipe". Paste copied text (for example from Live Text in the Camera)
  into "Paste a whole recipe" and tap "Fill in the form for me". These are saved on the iPad only.
